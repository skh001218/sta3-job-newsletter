# 작성 템플릿

## Notion 뉴스레터 페이지

```markdown
# [뉴스레터 전체 제목]

> [조사 목적, 조사일, 언어와 기간 등 수집 기준]

## [자료 제목]

### [자료에 맞게 추천한 소제목]

[소제목과 관련된 핵심 내용]

### [필요할 때 추가하는 소제목]

[추가 핵심 내용]

### 주목할 내용

- [중요한 수치, 사례 또는 실무 관점]
- [게임DA 관점에서 생각해 볼 질문]

### 참조

- 자료명: [원문 자료명]
- 발행처: [회사·기관·매체]
- 발행일: [확인된 날짜 또는 확인되지 않음]
- 근거 수준: [공식 / 학술 / 전문 매체 / 기타 참고]
- 원문: [원문 주소]

### 추천하는 이유

[게임 데이터 분석 직무 또는 실무 준비와 연결되는 이유]
```

## Slack 요약 메시지

```text
[뉴스레터 전체 제목]

[자료 번호]. [자료의 큰 제목]

주요 내용
[핵심 내용 1~2문장]

참조
[발행처] · [발행일] · [근거 수준]
[원문 주소]

━━━━━━━━━━━━━━━━━━
```

Slack 메시지에는 `큰 제목 / 주요 내용 / 참조`만 넣는다. 자료 사이에 빈 줄과 구분선을 둔다.
